BAT DAU SU DUNG UTH TODO

1. Giai nen file UTHTodo_AndroidStudio.zip.
2. Mo Android Studio > Open.
3. Chon thu muc UTHTodo (co file settings.gradle.kts).
4. Cho Gradle Sync; cai Android SDK Platform 36 neu Android Studio yeu cau.
5. Chay may ao Android va bam Run.

Package: com.example.uthtodo
Minimum SDK: 24
Compile SDK: 36
JDK: 17

Xem README.md de biet cau truc project va cach ap dung OOP.
